# 作業完了時の標準フロー

実装フェーズ完了時に **必ず** 通す5ステップ。

このフローは Claude のメモリ (`keirin_v2_completion_workflow.md`) でも管理されているが、Codex / Gemini 連携時の共通参照として docs にも置く。

---

## 標準フロー (5ステップ)

```
1. テスト通過確認
   pytest 全件パス + dry-run 7警告ゼロ

2. codex / gemini レビュー  [必須]
   docs/codex_gemini_review_workflow.md 参照
   指摘があれば追加コミットで対応

3. コミット作成 (必要なら複数)
   Co-Authored-By 行を含める

4. メモリ保存  [必須]
   Claude のメモリディレクトリに新規知見/教訓/方針を記録
   (~/.claude/projects/<project>/memory/)

5. ユーザー報告
   実装内容 / テスト件数 / dry-run / コミットハッシュ
```

ステップ **2 (codex/gemini)** と **4 (メモリ保存)** が「省略しがちだが必須」のステップ。

---

## メモリ保存の判断基準

### 保存すべきもの

- ユーザーが明示した方針 (「常に X してほしい」「Y は禁止」等)
- 新規ロジックの背景/Why
- 数値閾値・係数の根拠
- codex/gemini レビュー教訓
- 作業スタイルの好み

### 保存しないもの

- 個別 fixture 詳細
- 具体的なコミットハッシュ
- 一時的な作業状態
- コードに既に書かれている内容

---

## 例外 (省略可能なケース)

| 例外 | レビュー | メモリ保存 |
| --- | --- | --- |
| 軽微な修正 (typo/文言調整のみ) | 省略可 | 基本省略 |
| ユーザーから「次へ」明示指示 | 省略可 | 判断 |
| **ユーザー方針を含む修正** | 通常 | **必ず保存** |
| **新しい禁止/必須事項発見** | 通常 | **必ず保存** |
