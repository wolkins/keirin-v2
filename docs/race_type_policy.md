# 競輪予想：レース種別ごとの注意項目（実装仕様）

このドキュメントは、F2 / F1 / グレードレース / 新人戦 / ガールズで、
同じ予想ロジックを使い回さないための実装方針を定める。

レース種別ごとに、重視する情報・危険な判断・買い目生成の方針を切り替える。

---

## ステータス

| 状態 | 内容 |
| --- | --- |
| 現状 | ガールズ / 新人戦 / 安い人気筋分離 / ガミ判定 / 押さえ⇆本線昇格 を実装済 |
| **フェーズA (グレードレース対応)** | ✅ 完了 (race_grade判定 + 格上加点 + 決勝係数) |
| **フェーズB (F1/F2 判別)** | ✅ 完了 (チャレンジ判別 + F2点数差/3車加点 + F1強化) |
| **フェーズC (地元・地区連係)** | ✅ 完了 (home_area + 会場地区 + 地元加点) |
| 次のターゲット | 実レース fixture で出力検証 / Kドリームス取得時の home_area 連携 |
| 着手方針 | **段階的に進める**（一括ではなく、グレードレース対応から） |

全レース共通で以下を必ず見る。

- 別線番手
- 単騎

# 1. F2

## 特徴

F2はA級・チャレンジ・ガールズなどが中心。
選手間の力差が比較的大きく、若手先行や点数上位の地力がそのまま出ることがある。

ただし、下位戦では脚力差・展開差・番手の技量差が大きく、荒れも出る。

## 重視する項目

- 先行力
- B数
- 逃げ・捲りの決まり手
- 若手自力の力
- 点数差
- ラインの長さ
- 番手の追走力
- 地元番手
- チャレンジでは新人・若手の脚力
- A級一般では点数上位よりも展開・前々
- 準決・決勝では勢いと勝ち上がり内容

## 注意点

- 点数差が大きい場合は素直に力上位を重視する
- ただし番手が弱い場合は、先行頭でも2着番手固定にしない
- チャレンジでは若手自力が抜けていれば頭固定しやすい
- A級一般では低点数でも先行1車・番手有利で残る
- 3番手・4番手の流れ込みも比較的出やすい
- 本線が安くなりやすいため、ガミに注意する

## 買い目方針

- 基本は本命自力ライン中心
- 番手差しも必ず残す
- ラインが長い場合は3番手・4番手の3着を残す
- 別線番手の2着・3着を押さえる
- 本線が安い場合は、3着ズレで配当を取る

## F2で避けること

- 点数だけで追い込み選手を頭にしすぎる
- 若手先行の番手を無条件で信頼する
- 安い1-2-3だけに寄せる
- チャレンジで実力差を軽視する

# 2. F1

## 特徴

F1はS級戦とA級戦が混在する。
S級ではライン戦の質が高く、番手差し・別線番手・3番手の突っ込みが重要。
A級では特選・準決・決勝で力上位が揃う。

F2より選手の駆け引きが強く、単純な先行逃げ切りだけでは決まりにくい。

## 重視する項目

- ライン構成
- 番手選手の格
- S級点数
- 近況の着順
- 初日特選組
- 準決の内容
- 自力の仕掛けタイミング
- 番手差し
- 別線番手
- 3番手の伸び
- 単騎の位置取り
- オッズの偏り

## 注意点

- 番手選手の格が高い場合、番手頭を本線級にする
- S級では本命自力が早めに踏むと番手差しが起きやすい
- 別線の番手が高得点なら2着・3着に必ず入れる
- 3番手が実力者の場合、3番手2着上がりも残す
- 単騎の追い込み型が3着に入ることがある
- 本命ラインだけでなく、別線ラインのワンツーも押さえる

## 買い目方針

- 本線：line_leader - second - third
- 差し本線：second - line_leader - third
- ズレ目：line_leader - separate_second - second
- 別線：separate_leader - separate_second - main_leader
- 穴：separate_second - separate_leader - main_leader
- 単騎は3着穴中心

## F1で避けること

- 自力頭だけを過信する
- 番手格上を軽視する
- 別線番手の差し込みを消す
- 本線3番手の2着上がりを無視する
- オッズ安い本線だけに寄せる

# 3. グレードレース

## 対象

- G3
- G2
- G1
- GP
- 記念競輪
- 特別競輪

## 特徴

グレードレースは選手の格が高く、ライン構成・地区連係・番手の格・勝ち上がり条件が非常に重要。

通常F1/F2よりも、単純な点数差だけでは決まらない。
自力型も番手型も強く、展開と位置取りの比重が大きい。

## 重視する項目

- ラインの地区構成
- 番手選手の格
- 競輪祭/G1/G2/G3実績
- 直近の勝ち上がり内容
- 初日特選・二次予選・準決の内容
- 先行選手の主導権意欲
- 番手の仕事
- 3番手の格
- 単騎実力者
- 地元選手
- 競りの有無
- 勝ち上がり条件
- 決勝進出条件
- 準決・決勝ではラインの結束

## 注意点

- 番手が格上なら番手頭を本線級にする
- 3番手が実力者なら3着固定ではなく2着上がりも見る
- 単騎でもG1級なら2着・3着に入れる
- 地元番手・地元3番手は補正する
- ラインの先頭が若手の場合、番手が差す形が増える
- 準決・決勝では展開より「勝つ動き」をする選手を評価する
- 記念の序盤は地元勢の勝負気配に注意する
- 強い自力が複数いる場合、踏み合いから別線番手が浮上する

## 買い目方針

- 本線はライン構造重視
- 番手頭を厚めにする
- 3番手の2着上がりを残す
- 別線番手頭を穴で残す
- 単騎格上を3着以上で残す
- 地元ラインは過小評価しない
- 人気本線が安い場合はズレ目で配当を狙う

## グレードレースで避けること

- スコア順だけで本線を作る
- 地区ラインを無視する
- 番手格上を軽視する
- 単騎格上を消す
- 先行選手の格だけで頭固定する
- 競りやライン分断を無視する
- 初日/準決/決勝の勝負度を同じ扱いにする

# 4. 新人戦

## 対象

- ルーキーシリーズ
- 男子新人戦
- 女子新人戦
- `class_name` に「新人」「男予」「女予」「ルーキー」が含まれるレース

## 特徴

新人戦はデータが少なく、通常の競走得点やライン実績があまり当てにならない。
固定ラインがない場合も多く、個人戦に近い。

通常のライン戦ロジックをそのまま使わないこと。

## 重視する項目

- 在所成績
- 卒業記念成績
- 初日・2日目の実戦内容
- 直近着順
- 自力の有無
- 先行意欲
- 捲り脚
- レース慣れ
- 位置取り
- 前々に踏めるか
- 風の影響を受けにくい走り
- オッズ
- 1着経験
- 2着・3着の安定感

## 注意点

- 固定ラインを前提にしない
- 「番手」「ライン3番手」という言葉を安易に使わない
- 実戦経験が少ないため、人気順通りに決まらないことがある
- 1着経験のある中穴を2着以上に残す
- 強風では逃げ切りより中団・好位確保を重視する
- オッズが極端に偏る場合はガミ注意
- 2着・3着に中穴が入りやすい

## 買い目方針

- 本線は力上位2〜3名中心
- ただし1-2-3固定にしすぎない
- 中穴の2着上がりを押さえる
- 4番手評価の頭・2着を少し残す
- 風が強い場合は好位型・追走型を上げる
- 本線は最大3点程度
- 押さえは最大4点程度
- 穴は最大2〜3点程度
- 大穴は出しすぎない

## 新人戦で使う表現

使ってよい表現：

- 好位確保
- 前々
- 中団
- 追走
- 位置取り
- 捲り
- 仕掛け
- 実戦慣れ
- 風を受けにくい位置
- 中穴2着
- 追走型3着

使ってはいけない表現：

- 番手
- 本命ライン
- 別線番手
- ライン3番手
- line_leader
- second
- third

## 新人戦で避けること

- 通常ライン戦のロジックを使う
- スコア順だけで本線を固定する
- 人気1-2-3だけを厚くする
- 中穴2着を消す
- 実戦内容を無視する
- オッズ未取得だけを一番買いたい買い目にする

# 5. ガールズ

## 特徴

ガールズは固定ラインがない。
位置取り・自力・追走力・直近内容・安定感が重要。

通常ライン戦のロジックを絶対に混ぜないこと。

## 重視する項目

- 競走得点
- 直近着順
- 初日内容
- 2日目内容
- 自力の有無
- 捲り脚
- 逃げ脚
- 追走力
- 位置取り
- 前々に踏めるか
- 2着・3着の安定感
- オッズ
- 市場人気
- ガミリスク
- 強風時の位置取り

## 注意点

- ラインなし
- 番手という表現は禁止
- 別線番手という表現は禁止
- ライン3番手という表現は禁止
- 点数上位だけで決めない
- 市場オッズをかなり重視する
- ガールズは直近内容や位置取りがオッズに反映されやすい
- 極端に安い人気筋は本線ではなく「安い人気筋・ガミ注意」に分ける
- 「見送り寄り」を一番買いたい買い目に出さない
- 本線がオッズ未取得だけにならないようにする
- 中穴2着・追走型3着を必ず検討する

## ガールズの買い目方針

### 本線

- 力上位頭
- 対抗2着
- 3着は安定型・追走型

例：

- 本命頭 - 対抗 - 安定型
- 本命頭 - 中穴 - 対抗
- 対抗頭 - 本命 - 安定型

### 押さえ

- 対抗頭
- 中穴2着
- 追走型3着
- 市場人気上位

### 穴

- 中穴頭
- 人気上位の一角崩れ
- 位置取り上手い選手の2着
- 追走型3着

### 安い人気筋・ガミ注意

`market_odds` が極端に低い場合は、別枠に分ける。

例：

- 1-2-3 2.3倍
- 1-2-4 4.2倍

これは本線候補ではあるが、厚く買う候補ではない。
「ガミ注意」「買うなら少額」「見送り寄り」として表示する。

## ガールズで避けること

- 番手表現
- 本命ライン表現
- 別線番手表現
- ライン3番手表現
- スコア順だけで本線を作る
- オッズを無視する
- 2倍台・4倍台の買い目を一番買いたいに出す
- 見送り寄りを一番買いたいに出す
- 穴を広げすぎる

# 出力カテゴリの共通ルール

## 本線

実際に買いたい中心候補。
ただし、安すぎる場合は「安い人気筋・ガミ注意」に分離する。

## 押さえ

本線の裏目、別線、2着・3着ズレ。
実購入候補として使えるもの。

## 穴

少額で足す候補。
点数を広げすぎない。

## 大穴

原則少なめ。
明確な根拠がない場合は出さない。

## 安い人気筋・ガミ注意

以下の条件に該当する買い目は、別枠にする。

- `market_odds < 5`
- `value_label = 見送り寄り`
- `gami_risk >= 0.8`
- 人気が集中しすぎて回収が難しい

この枠の買い目は「一番買いたい買い目」に出さない。

---

# 最終結論のルール

最終結論は候補羅列にしない。

必ず以下に分ける。

1. **一番買いたい買い目**
   - 最大2点
   - `value_label` が 本線向き / 妙味あり
   - `gami_risk` が低い
   - `market_odds` が低すぎない
   - line構造または個人戦評価が自然

2. **押さえるべき買い目**
   - 最大4点

3. **少額で足す穴**
   - 最大2点

4. **安い人気筋・ガミ注意**
   - 厚く買わない
   - 買うなら少額
   - 見送り寄りなら明記

5. **見送り寄り**
   - 買わない候補
   - 参考表示のみ

## 実購入判断サマリ

5点目安（本線2〜3 / 押さえ2 / 穴1）で記述する。

```
- **本線として有力**: <combo> / <combo>（本線2〜3点を中心に）
- **押さえとして必要**: <combo> / <combo>（押さえ2点）
- **少額の穴**: <combo>（1点までを目安に）
- **<cheap>** は売れすぎ / ガミ注意 → 厚く買わない（確認程度）
```

# ガミ判定ルール

以下はガミ注意。

- `market_odds < 5`
- `market_odds < 15` かつ `gami_risk >= 0.6`
- `market_odds < 20` かつ `gami_risk >= 0.8`

以下はガミ注意にしない。

- `market_odds >= 20`
- `market_odds is None`
- 穴・大穴でオッズが20倍以上

3連複が極端に安い場合でも、関係ない買い目にガミ警戒を波及させない。
**該当組み合わせだけに適用する。**

---

# データ不足時のルール

競走得点・B数・決まり手が未取得の場合は、以下を明示する。

> 「競走得点・B数・決まり手が未取得のため、オッズ・脚質コメント・並びを強めに参照しています」

データ不足時は以下を重視する。

- オッズ
- 3連複
- 脚質コメント
- 並び
- 直近結果
- バンク傾向

`score == 0.0` の場合は、原則 `stats_missing = true` とする。
本当に0である可能性は低いため、取得失敗として扱う。

# LLMの役割

LLMは買い目を作り直さない。

**LLMの役割：**

- 説明文を自然にする
- 本線・押さえ・穴の理由を整理する
- ガミ回避メモを書く
- 最終結論を分かりやすくする

**LLMにやらせないこと：**

- 買い目を新規作成
- `honsen` / `osae` / `ana` / `ooana` を勝手に変更
- 見送り寄りを一番買いたいにする
- ガールズや新人戦にライン表現を混ぜる
- 的中保証する

# 未確定事項 / デフォルト案

実装着手前に確定したい項目。当面は**デフォルト案**で進める。

## Q1. 「番手の格」「3番手の格」「単騎格上」の閾値

**デフォルト案（要確認）**:

| 種別 | 「格上」判定 |
| --- | --- |
| F2 / 新人戦 | 競走得点 ≥ 85 で「格上」 |
| F1 | 競走得点 ≥ 95 で「格上」 |
| グレードレース | 競走得点 ≥ 100 で「格上」 |

将来 `Rider.class_score`（S級点数）が取得できるようになれば、点数基準に置き換える。

## Q2. 「準決・決勝」「初日特選」の判定

**デフォルト案**: `class_name` 部分一致で判定。

| フラグ | キーワード |
| --- | --- |
| `is_final` | "決勝" |
| `is_semi_final` | "準決" / "準決勝" |
| `is_tokusen` | "特選" |
| `is_first_day` | "初日" / 開催1日目 |

`race_no` ベースの判定はバンクごとに違うため、当面 `class_name` 優先。

## Q3. 「地元選手」「地区連係」

**デフォルト案**: 当面は user_note 経由で受け取り、フェーズ C でデータ取得拡張。
